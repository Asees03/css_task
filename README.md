# css_task
This file demonstrates different CSS selectors and styling techniques using HTML elements.

Topics Covered
Element selectors
Class selectors
ID selectors
Attribute selectors
Pseudo-classes
Pseudo-elements 
Text and background styling
Ordered and unordered list styling
Files
index.html – Contains the HTML elements.
style.css – Contains the CSS rules used to style the elements.
How to Run

Open index.html in any web browser to view the output.
